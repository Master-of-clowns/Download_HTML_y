# Парсер Яндекс Видео

Работай из корня репозитория, где находятся `run.py`, `requirements.txt` и `README.md`. Сохраняй простой интерфейс и компактную структуру: реализация в `run.py`, зависимости в `requirements.txt`, README только про запуск. Этот файл описывает работу агента с проектом; сам по себе он не устанавливает скилл глобально.

## Запуск и контракт

```bash
python3 -m pip install -r requirements.txt
python3 run.py input.json output.json
```

Второй аргумент необязателен: по умолчанию результат пишется в `result.json` текущей папки. Chromium при необходимости устанавливается автоматически в `.browsers` рядом со скриптом.

Вход — JSON-объект или массив объектов:

```json
{"query": "арма 3 локальная сеть", "region_id": 977, "device": "desktop"}
```

`query` — непустая строка, `region_id` — положительное целое число, `device` — `desktop`, `mobile` или `tablet`. На выходе сохраняются форма объекта/массива, порядок элементов и дополнительные поля; добавляется или заменяется `url` со ссылкой на HTML в S3. Выходной файл записывается атомарно после успешной обработки всех элементов. При ошибке уже загруженные объекты S3 могут остаться, но прежний выходной файл сохраняется.

## Настройки и доступы

Ключи `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` и параметры корзины берутся из окружения либо `.env` рядом с `run.py`. Окружение имеет приоритет над `.env`.

- `S3_BUCKET` — обязательное имя корзины.
- `S3_ENDPOINT_URL` — по умолчанию `https://s3.twcstorage.ru`.
- `AWS_DEFAULT_REGION` — `ru-1`.
- `S3_PREFIX` — `yandex-video`.
- `S3_URL_MODE` — `presigned` или `public`, по умолчанию `presigned`.
- `S3_URL_TTL_SECONDS` — срок подписанной ссылки, по умолчанию 86400 секунд, максимум 604800.
- `S3_PUBLIC_BASE_URL` — необязательный базовый адрес для режима `public`; этот режим требует доступности объектов для чтения.

Таймауты, число попыток, лимит HTML и настройка прокси задаются в `settings()` в коде. Не возвращай их в переменные окружения без запроса пользователя.

Не читай и не печатай секретные значения или содержимое `.env`. Не добавляй ключи, `.env`, `.venv`, `.browsers`, кеши и `.DS_Store` в Git или переносимый архив. Подписанные URL содержат доступ: при диагностике скрывай параметры подписи.

## Требования к сохранённой странице

- Используй анонимную сессию Chromium без входа в аккаунт. Cookies внутри запроса нужны для настройки поиска.
- Передавай `region_id` через `lr` и проверяй регион после переходов. Это регион поиска, а не география IP.
- Настраивай User-Agent, размер экрана и мобильный режим по `device`.
- Отключай размытие 18+ контента и проверяй итоговое `showSensitive=true`. Одного параметра `show_sensitive=on` недостаточно: нужен существующий механизм настройки с cookies. Не выводи сессионный ключ настройки.
- Дожидайся загрузки карточек текущей страницы, прокручивай их для загрузки превью. Кнопка «Ещё видео» не входит в текущую границу загрузки.
- Сохраняй отрендеренную страницу через MHTML, встраивай ресурсы в самостоятельный HTML. При отсутствии charset используй UTF-8; учитывай ссылки ресурсов вида `//...` и `&amp;`.
- Сохраняй переходы по видео на Яндекс через корректные адреса и `<base>`, чтобы они не превращались в ссылки на S3.
- Проверяй HTML в браузере без сети перед загрузкой: карточки и превью видны, нет скелетонов и исполняемых скриптов. Явное сообщение «Видео по вашему запросу не найдено» допустимо. Капчу или неполную страницу не выдавай за успешный результат.

## Изменения и проверка

Перед изменением прочитай соответствующие функции `run.py`. При исправлении загрузки проверяй видимый результат, а не только HTTP 200 или совпадение байтов S3. Для проверки сохранённой страницы блокируй внешнюю сеть: превью должны открываться из встроенных ресурсов.

Используй имеющиеся тесты, если они доступны в рабочем окружении; не считай локальные диагностические файлы обязательной частью репозитория. Проверяй затронутое поведение: регион, устройство, отсутствие размытия, полноту превью, адреса видео, сохранение JSON и обработку ошибок. Реальный запуск загружает объекты в S3; выполняй его в рамках запроса на прокачку или согласованную проверку. В отчёте разделяй локальные проверки и реально выполненный сетевой запуск.

Если обрабатываешь таблицу, извлекай номер региона из её значения, например `Калининград (22)` → `22`, без подмены регионом по умолчанию. Сохраняй соответствие строк, устройств и результатов; меняй только запрошенные столбцы и сохраняй маркеры «ок / не ок».
